# Module Guides — présentation (thème)

Pendant du module `guides` de `gws-core` (données/logique). Voir son README pour activer le
module côté plugin et remplacer le contenu d'exemple.

## Activer l'affichage

Copier tout le dossier `page-templates/` de ce module vers `page-templates/` à la racine du
thème (il contient `guide.php` et `guides-hub.php`, aux chemins exacts attendus par le module
côté plugin — ne pas les renommer). Le hub et les pages d'exemple sont créés automatiquement au
premier chargement une fois le module activé côté plugin (`config/modules.php`).
